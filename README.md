# 🏆 FIFA World Cup 2026 Digital Hub

![FIFA World Cup 2026](https://images.unsplash.com/photo-1518605368461-1ee7e53f1917?auto=format&fit=crop&q=80&w=1200)

Welcome to the **FIFA World Cup 2026 Fan Play** repository! This is a premium, highly immersive digital experience companion for the historic 2026 FIFA World Cup, spanning the USA, Canada, and Mexico.

Built with a deep passion for football and modern web design, this hub serves as a central platform for fans to explore fixtures, build squads, predict brackets, and dive into World Cup history.

## ✨ Key Features

- 🕰️ **Dynamic Match Tracker**: A real-time, background-powered "Next Match" indicator seamlessly integrated into the navigation bar.
- 📅 **Fixtures & Groups**: Interactive interfaces mapping out all 104 matches, 12 groups, and 16 host cities/stadiums.
- 🔮 **Bracket Predictor**: A complete knockout engine mapping the Round of 32 all the way to the Final.
- 🛡️ **Squad Builder**: Formulate your ultimate starting XI in an interactive pitch view.
- 📚 **Memories & History**: Relive the magic of past tournaments with curated stories, "Did You Know?" facts, and quotes.
- 🌟 **Icons & Champions** *(Coming Soon)*: Scroll through the legends of the game (from Pelé to Messi) and explore a classic Wall of Champions since 1930.
- 🎨 **Premium Aesthetic**: Powered by Framer Motion, the UI features glassmorphism, dynamic color themes based on your selected nation, and incredibly smooth micro-animations.

## 🛠️ Technology Stack

- **Frontend**: React (Vite), Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Architecture**: Monorepo workspace structure (Client & Backend)

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and npm installed. Setup your MongoDB URI and API configs in `backend/.env`.

### Installation

Install dependencies for both the client and backend simultaneously:

```bash
npm run bootstrap
```

### Running Locally

Start both the React development server and the Express backend API concurrently:

```bash
npm run dev
```

- **Client**: `http://localhost:5173` (or whichever port Vite allocates)
- **Backend**: `http://localhost:5000`
