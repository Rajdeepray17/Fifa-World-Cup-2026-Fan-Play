# FIFA WORLD CUP 2026 MERN Starter

This repository contains a premium‑ready starter skeleton for a full‑stack MERN application.

- **client/** – React frontend (Vite).
- **server/** – Express backend with MongoDB.
- Workspace scripts allow running both parts concurrently.

## Setup

1. Make sure `server/.env` exists with the MongoDB URI and backend port.
2. Install dependencies:

```bash
npm install
```

3. If you want to reinstall both workspace packages explicitly:

```bash
npm run bootstrap
```

4. Start both apps:

```bash
npm run dev
```

## Getting Started

```bash
# Run both services after install
npm run dev
```

Feel free to adjust the design system, add authentication, Docker, or TypeScript as needed.
